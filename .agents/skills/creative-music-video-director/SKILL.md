# Creative Music Video Director Skill

This skill equips the agent with professional music video (MV) direction standards, focusing on rhythm-synchronized visual pacing, narrative structure, thematic visual metaphors, and emotional arc management for code-driven and generative MVs.

## 1. Core Principles of Lyric & Beat Choreography

1. **Hierarchy of Synchronization**:
   - **Macro Rhythm (Bar/Phrase Level)**: Scene changes, camera transitions, thematic lighting shifts, and major emotional posture transformations should align with musical phrases (typically 4 or 8 bars).
   - **Micro Rhythm (Syllable/Transient Level)**: Drum kicks, snare hits, vocal transients, and syllabic staccatos trigger micro-animations: scale bumps, glow flashes, chromatic glitch pulses, or kinetic typography sweeps.
2. **Visual Metaphor Formulation**:
   - Translate abstract lyrical concepts into visual physics:
     - Initialization / Boot -> Circuit ignition, CRT scanline startup, binary stream rainfall.
     - Object creation / Memory allocation -> Wireframe mesh instantiation, holographic bounding boxes.
     - Mathematical functions -> Dynamic coordinate planes, tangent vectors, wave propagation.
     - Execution / Climax -> System fault escalation, buffer overflow artifacts, chromatic aberration, dimensional tearing.
     - Collapse / Self-termination -> Particle dissolution, CRT power-off focal point decay.

## 2. Emotional Arc & Pacing Model

A standard 3 to 4-minute music video follows a 5-phase narrative curve:

| Phase | Musical Function | Visual State & Choreography | Pacing / Camera Dynamics |
| :--- | :--- | :--- | :--- |
| **I. Awakening (Exposition)** | Ambient intro, soft beat | Clean, dark, minimal. Dim luminescent lines, idle or dormant character. Minimal glitch damage. | Slow creeping push-in (Slow Track), subtle breath float. |
| **II. Construction (Rising)** | Steady beat establishes, rhythmic cadence | Interactive elements activate, code flows, coordinate axes construct, character awakens into active thinking. | Moderate pan and tilt, rhythmic scale impulses on the snare. |
| **III. Iteration (Bridge)** | Complex layers, tension build-up | Math equations expand, multiple visual layers overlap, slight digital artifacts appear. | Alternating Dutch angles, quick cuts between character focus and environmental geometry. |
| **IV. Execution (Climax)** | Maximum frequency density, peak vocal intensity | Overclocking visuals: RGB split, screen shake, red/magenta alarm accents, explosive particle bursts, dynamic action poses. | Aggressive camera zooms, whip pans, heavy chromatic glitch. |
| **V. Termination (Outro)** | Beat fades, solitary melody or silence | System collapse, fading embers, character dissolving or falling into silent void, final heartbeat blink. | Slow pull-back to infinity, aperture blackout or single pixel shrink. |

## 3. Kinetic Typography Integration

- **No Static Subtitles**: Subtitles must behave as active visual actors.
- **Focal Elevation**: The current singing phrase takes the visual center of gravity, scaling up with high-luminous contrast while preceding/succeeding phrases recede with depth-of-field blur.
- **Progressive Sweep**: Light sweeps across glyphs exactly timed to phoneme articulation.
